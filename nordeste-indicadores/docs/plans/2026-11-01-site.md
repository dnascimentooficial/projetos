# Site Nordeste em Números — Plano de implementação

> **Para agentes:** SUB-SKILL OBRIGATÓRIA: use superpowers:subagent-driven-development (recomendado) ou superpowers:executing-plans para executar este plano tarefa a tarefa. Os passos usam checkbox (`- [ ]`).

**Objetivo:** gerar, a partir da base publicada, o site estático `https://nordeste.dnascimento.com.br` e publicá-lo automaticamente toda semana pela Hostinger.

**Arquitetura:** novo subpacote `nordeste.site` (dados → conteúdo → gráficos SVG → páginas Jinja2 → estáticos e imagens) acionado por `python -m nordeste site`; módulo `nordeste.automacao` com a lógica do robô; workflows do GitHub Actions finos que chamam esses comandos; o hPanel puxa a branch `site-publicado`.

**Tecnologia:** Python ≥ 3.12, pandas, pyyaml, Jinja2 (nova), Playwright para Python (nova, extra `site`), Chromium sem tela, axe-core (arquivo versionado nos testes), JavaScript e CSS sem bibliotecas.

**Spec:** `docs/specs/2026-11-01-site-design.md` (repositório novo: mesmo caminho na raiz). Protótipo de referência visual e de textos: https://claude.ai/artifact/4Ekqm88b9JvsyzdLriFi7f (fonte: `files/index.html` do painel; o controlador entrega uma cópia ao implementador quando a tarefa pedir).

## Restrições globais

- Comandos a partir da raiz do repositório `nordeste-em-numeros`; suíte `python -m pytest -W error` verde ao fim de cada tarefa.
- O site lê só `dados/base/`, `dados/relatorios/` e `metadados/`; nunca `dados/trabalho/` nem `dados/brutos/`.
- Mesma base publicada → site idêntico byte a byte (ordenação estável, sem datas do relógio; a data exibida é a da publicação da base).
- Nenhum número digitado em template ou YAML de texto: todo número vem de um marcador preenchido pela base.
- Nada interpolado, projetado ou emendado; séries de pesquisas diferentes são linhas separadas; ano sem dado fica em branco.
- Nenhum recurso externo nas páginas (fontes, scripts, estilos e imagens locais); Content-Security-Policy `default-src 'self'`.
- Endereço canônico: `https://nordeste.dnascimento.com.br/`; `<html lang="pt-BR">`; números em formato brasileiro (`1.234,5`).
- Cores: `#ea2e00`, `#c42600` (texto pequeno em fundo claro), `#080808`, `#f5f4ef`, `#ffffff`. Fontes: Manrope (títulos), DM Sans (texto), `woff2` locais com a licença OFL ao lado.
- Movimento só com `prefers-reduced-motion: no-preference`; nenhum conteúdo depende de animação para aparecer.
- Texto: primeira pessoa, sem travessão (—), sem intensificadores, sem atribuir resultado a governo.
- Imagens: OpenGraph 1200×630; card 1080×1350. Licença da compilação: CC BY 4.0.
- Commits terminam com as linhas de atribuição da sessão de quem os escreve.

## Foco de revisão

1. Indicador sem dado para um território no Explorar (ex.: IDHM do Nordeste antes de 2012, Brasil fora do NE sem a série) → a vista mostra "Este indicador não tem dados para este território", sem gráfico vazio nem erro. (Teste na Tarefa 6.)
2. Fecho ou card cuja condição cita um destaque que sumiu da base → condição falsa, fecho suprimido e listado no relatório, sem quebrar a geração. (Teste na Tarefa 3.)
3. Valores longos no celular (R$ 2.554, "Brasil fora do Nordeste", 2,19 mi) a 390 px → nada estoura a largura. (Teste na Tarefa 9.)
4. Série que não atualizou na semana → o indicador mostra "atualizado em" com a data da coleta antiga e o site gera normalmente. (Teste na Tarefa 2.)
5. hPanel não puxou a publicação → o teste de fumaça percebe o sha256 antigo no rodapé e abre issue. (Teste na Tarefa 11.)
